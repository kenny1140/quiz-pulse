# ⚡ Quiz Pulse

An interactive, browser-based quiz application built with Vanilla JavaScript, HTML5, and CSS3. Designed for quick knowledge checks with instant feedback and persistent high-score tracking[cite: 11].

🔗 **Live Demo:** [kenny1140.github.io/quiz-pulse](https://kenny1140.github.io/quiz-pulse) *(update if GitHub Pages isn't enabled yet)*

---

## ✨ Features

* **Interactive Question Flow:** Dynamic DOM rendering for questions, answer choices, and real-time score calculation[cite: 11].
* **Persistent High Score Tracking:** Automatically saves and displays your personal best score across sessions using `localStorage`[cite: 11].
* **High-Contrast UI:** Clean, responsive layout with clear visual feedback and a readable high-score badge[cite: 11].
* **Zero Dependencies:** Built purely with standard web technologies—no frameworks or external libraries required[cite: 11].

---

## 🛠️ Tech Stack

* **HTML5** — Semantic structure (`index.html`)[cite: 11]
* **CSS3** — Responsive layout, custom badge styling, and contrast tuning (`styles.css`)[cite: 11]
* **JavaScript (ES6+)** — Quiz logic, state management, and `localStorage` persistence (`app.js`)[cite: 11]
